Entry for the make.fun competition **"One-Line Laugh Sprint"**. The program writes a single original funny line about everyday life (105 characters) to `/output/entry.txt`:

> I bought noise-cancelling headphones so I could hear myself think, and it turns out I had nothing to say.

## Run it

```bash
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To choose another
directory, set `MAKEFUN_OUTPUT_DIR`:

```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

No dependencies beyond Python 3.13's standard library, and no network access.
